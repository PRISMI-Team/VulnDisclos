# SKYWORTH AX1800M Unauthenticated Sensitive Information Disclosure (CVE-2026-78801)

## Summary

The application exposes a hidden factory interface without requiring authentication. An unauthenticated attacker may directly access the interface.

## Affected Product
- Vendor: SKYWORTH
- Product: SK-WR6640X Wi-Fi 6 Dual-Band Fiber Router (AX1800M) 
- Affected Versions: V1.0.3

## Timeline
- 2026/5/15 - Vulnerability discovered during security testing of the SK-WR6640X Wi-Fi 6 Dual-Band Fiber Router (AX1800M) router.
- 2026/6/12 - Requests to MITRE for CVE.
- 2026/9/14 - Publicly disclosed
