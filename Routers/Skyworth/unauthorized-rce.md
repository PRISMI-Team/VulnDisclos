# SKYWORTH AX1800M Unauthenticated remote code execution(CVE-2026-78802)

## Summary

The device exposes hidden web endpoints that lack adequate access controls, allowing an attacker on the adjacent network to access sensitive device information and invoke privileged functionality. Successful exploitation may enable disclosure of device credentials or authentication-related information, activation of remote management services, and ultimately unauthorized root-level access.

## Affected Product
- Vendor: SKYWORTH
- Product: SK-WR6640X Wi-Fi 6 Dual-Band Fiber Router (AX1800M) 
- Affected Versions: V1.0.3

## Timeline
- 2026/5/20 - Vulnerability discovered during security testing of the SK-WR6640X Wi-Fi 6 Dual-Band Fiber Router (AX1800M) router.
- 2026/6/12 - Requests to MITRE for CVE.
- 2026/9/14 - Publicly disclosed
